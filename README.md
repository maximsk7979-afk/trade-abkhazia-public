# trade-abkhazia-public

Публичное зеркало базы знаний (`kb/`) проекта **Trade Abkhazia** (торговая система учёта и ИИ-агент Ева).

## Назначение

Этот репозиторий — **read-only зеркало** актуального состояния базы знаний из приватного основного репо.

Используется ИИ-агентами, работающими над проектом:
- **Архитектор** (Claude.ai в браузере) — для чтения базы знаний при проектировании
- **Чат** (ChatGPT) — для контекста при структурировании заметок

## Ключевая ссылка

Карта всей базы знаний — [`kb/INDEX.md`](kb/INDEX.md).

Архитектор и Чат при старте каждого нового чата читают `INDEX.md`, дальше открывают только нужные файлы.

## Связанные репозитории

- **Приватный основной**: `github.com/maximsk7979-afk/trade-abkhazia` — база знаний и код (доступ только у Максима и CC)
- **Канал коммуникации**: `github.com/maximsk7979-afk/trade-abkhazia-comms` — ТЗ, ответы, история обмена между ИИ-агентами

## Правила использования

⚠️ **Этот репозиторий — read-only.** Никто, кроме CC, в него не пишет.

- Архитектор и Чат **только читают** через web fetch
- Изменения в базу знаний делает только **CC** (Claude Code) — он правит файлы в приватном репо, после чего изменения автоматически синхронизируются сюда

Если нужно что-то изменить в `kb/` — формулируется ТЗ и кладётся в [`trade-abkhazia-comms/inbox/`](https://github.com/maximsk7979-afk/trade-abkhazia-comms/tree/main/inbox) (через Максима).

## Синхронизация

Содержимое синхронизируется с приватным репо при каждом значимом изменении.

**Текущая синхронизация**: с приватным коммитом `af2374b` (автоматическая, GitHub Action).

После настройки автоматической синхронизации (GitHub Action) этот раздел перестанет быть актуальным — синхронизация будет происходить автоматически при каждом push в приватный репо.
