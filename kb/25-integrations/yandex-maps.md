# Yandex Maps

## Назначение

URL геолокации в карточке клиента (`ynavUrl`). Используется водителями для построения маршрута к клиенту.

## Параметры

- **Не API**, а просто URL вида `https://yandex.ru/maps/...`
- Хранится в карточке клиента, поле `ynavUrl`
- Никаких ключей, токенов, лимитов

## Кто оплачивает

Не оплачивается.

## Что делать при отказе

Yandex Maps как сервис — публичный. URL'ы в карточках клиентов работают, пока работает yandex.ru/maps. Отказ маловероятен.
