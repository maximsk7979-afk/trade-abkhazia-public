# 15-team — Конкретные люди

Заметки о людях, с которыми ведётся работа. Не дублирует БД.

## Принцип

> **Оперативные данные** (ID, роли, контакты, офис, активность) — единственный источник истины: БД, ключ `trade-cat-staff` или `trade-cat-clients`. Управление через интерфейсы фронтенда.
>
> **Этот слой** — только качественные характеристики, в БД нехранимые: на чём специализируется, особенности взаимодействия, контекст.

См. [ADR-004](../90-decisions/ADR-004-data-source-of-truth.md).

## Кого здесь нет

- **Все клиенты** — их сотни, они в `trade-cat-clients` (БД). Отдельные файлы создаём только для тех, с кем регулярное стратегическое взаимодействие.
- **Контрагенты-подрядчики** (водители, таможня, погранслужба) — в `trade-cat-contragents` (БД). Подробности про них — в [20-domain/settlements/contractors.md](../20-domain/settlements/contractors.md).
