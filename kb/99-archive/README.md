# 99-archive — Архив

Здесь живёт всё, что **устарело**, но **жалко удалять**:
- Старые версии файлов
- Завершённые AS-IS-описания после миграции
- Исторические снимки CONTEXT.md, ТЗ, документации

## Принципы

- **Не редактируем** содержимое архива — это история
- **Не используем** как источник информации в активной работе
- **Сохраняем** для случаев "понять, как было раньше"

## Что внутри

- [old-context-md/](old-context-md/) — копия исходного `CONTEXT.md` (до перехода на модульную базу)

## Когда добавляем

- При замещении документа новой версией — старая → сюда с датой
- При завершении миграции AS-IS-роли — `30-roles/as-is/<role>.md` → `99-archive/<year>-roles-as-is/<role>.md`
- При отказе от компонента — описание → сюда
