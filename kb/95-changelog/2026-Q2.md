**Инцидент**: 2026-05-08 VPS был остановлен Vultr из-за просрочки оплаты — часы простоя продакшена. После оплаты инстанс поднялся сам, всё работает. **Наблюдение про auto-memory CC**: при запуске CC из `~/` (а не из `~/Documents/trade_app/`) память не подгружается — Claude Code привязывает namespace памяти к cwd через хеш пути. Файлы протокола (`feedback_session_protocol.md`, `reference_kb_repo.md` и др.) лежат в `~/.claude/projects/-Users-skorokhodovmaxim-Documents-trade-app/memory/`. Решено схему не менять — на будущее запускать CC через `cd ~/Documents/trade_app && claude`, иначе протокол открытия сессии не сработает автоматически. Зафиксировано здесь для памяти на будущее.

**Демо-стенд для инвестора**: обсуждали поднятие отдельного `demo.trade-abkhazia.com` (отдельная БД `trade_db_demo`, отдельный PM2-процесс, синтетические данные). Решено не делать — долго, инвестору в этом цикле демо не показываем. Грузить демо-данные в продакшен признали неприемлемым (смешение с реальными справочниками).

## 2026-04-30 — Архитектура коммуникации между AI-агентами

Развёрнута трёхрепозиторная архитектура для совместной работы CC, Архитектора (Claude.ai) и Чата (ChatGPT) через GitHub.

### Созданы три репозитория

1. **`trade-abkhazia`** (приватный, существующий) — основной: `kb/` + код
2. **`trade-abkhazia-public`** (новый, публичный) — read-only зеркало `kb/`. Архитектор и Чат читают через web fetch.
3. **`trade-abkhazia-comms`** (новый, публичный) — канал коммуникации с папками `inbox/`, `responses/`, `archive/`, файлом `INDEX.md` и полным `README.md` с правилами именования, жизненным циклом документов, политикой архивирования.

### Поток ТЗ от Архитектора

- Архитектор формулирует ТЗ в чате с Максимом
- Файл сохраняется в локальной папке `~/Desktop/trade-inbox/` на Маке Максима с именем формата `YYYY-MM-DD-HHMM_architect_<тип>_<тема>.md`
- Команда CC: "Проверь рабочую папку"
- CC копирует файл в `comms/inbox/`, удаляет локальный, делает работу, пишет ответ в `comms/responses/`, обновляет `INDEX.md`
- Архитектор в новом чате читает обновления через web fetch

### Создан onboarding для Архитектора

- `kb/00-meta/architect-onboarding.md` — текст, который Максим копирует в начале каждого чата с Архитектором. Описывает роль, обязательные файлы для чтения, правила работы, формат и поведение.
- `kb/00-meta/templates/architect-task.md` — шаблон ТЗ полусвободного формата с полным примером.

### Принципы

- Запись в `kb/` и в `comms/` — только через CC (Архитектор и Чат не имеют git-доступа).
- Полная история коммуникации сохраняется (никакого удаления).
- Архивация в `archive/` — только с явного согласия Максима (защита от потери незавершённых задач при длительном отсутствии).

### Состояние

## 2026-04-29 (вторая часть) — Уточнение по словарю и порогу 50/100 ₽

- CONTEXT.md отставал от реализации.

Сделанные правки:
- [`georgian-dictionary.md`](../20-domain/invoices/georgian-dictionary.md) — переписано введение: словарь не использовался ботом, реальное назначение — для Евы при проектировании.
