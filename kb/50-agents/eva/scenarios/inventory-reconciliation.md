# Сценарий Евы: сверка остатков

> Взгляд Евы на процесс [ежедневной сверки остатков](../../../30-roles/to-be/warehouse/processes/inventory-reconciliation.md) (GAP-050). Ева — **интерфейс к одной системе** (ADR-025): остаток/сверку считает сервер (`stock-service`), Ева их читает и проактивит, ничего не пересчитывает.

## Что делает Ева

### 1. Вечернее напоминание кладовщику (проактив)
Крон `inventory-reminder-tick.js reminder` (≈19:00 МСК = 16:00 UTC): всем сотрудникам с ролью `warehouse` и привязанным Telegram — «Пора сверить остатки на складе, откройте «📋 Сверка»».

### 2. Утренняя сводка владельцу/ГД (проактив)
Крон `inventory-reminder-tick.js summary` (≈09:00 МСК = 06:00 UTC): `owner` + `gen_director` получают сводку за вчера — была ли сверка по каждому складу, сколько расхождений; если сверки не было — подсказка напомнить кладовщику.

### 3. Аналитика по запросу (диалог)
Через `get_business_data` topic **`inventory`** Ева отвечает на вопросы владельца/ГД/фин.директора:
- «Какие расхождения по сверке вчера?» / «Что не сошлось на складе?»
- «Где недостача/излишек, по каким товарам, сколько кг?»
- Оценка масштаба (например, усышка весовых в кг → ₽ по себестоимости из партий).

Топик `inventory` отдаёт шапку сверки + строки-расхождения (book/факт/Δ по местам и кг, причина). Только для `owner`/`gen_director`/`fin_director`.

## Чего Ева НЕ делает
- Не вводит сверку за кладовщика (ввод — только мини-апп, роль `warehouse`).
- Не считает остаток сама — берёт из системы (один калькулятор, ADR-025).
- Не проводит списания/корректировки — проводка реализована (GAP-065 фаза 2 ✅ 2026-07-06), но **только вручную владельцем/ГД в TradeApp** («Склад → ✂️ Усышка» → «Провести» у сверки). Ева подсказывает про непроведённые расхождения (утренняя сводка + диалог), сама не проводит.

## Реализация
- Топик: `code/eva/src/tools/get-business-data.js` (TOPIC_KEYS `inventory` → `trade-inventory-counts`).
- Знание: `code/eva/src/system-prompt.js` (раздел «Сверка остатков»).
- Проактив: `code/eva/src/inventory-reminder-tick.js` (режимы `reminder`/`summary`, crontab на VPS).
