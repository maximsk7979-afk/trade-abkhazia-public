# _shared — Общее для всех агентов

> ⏳ Заглушка. Наполнение по мере проектирования Евы — выделим сюда то, что применимо не только к ней.

## Что сюда попадёт

- **architecture.md** — базовая архитектура агента: память, инструменты, роутер, цикл диалога
- **memory-protocol.md** — протокол памяти: что и как агент помнит между сессиями
- **prompt-conventions.md** — соглашения по промптам (системный, ролевой, инструменты)
- **tool-protocol.md** — как агент вызывает инструменты, что возвращает

## Принцип

Когда мы проектируем Еву и видим, что какое-то правило/компонент/протокол **не специфичен для неё**, а применим к **любому** агенту — выделяем сюда.

Будущий финагент будет использовать `_shared/` как базу + добавлять свою специфику.

## Префикс `_`

Подчёркивание перед именем — стандартный приём, чтобы папка визуально отделялась от других агентов и сортировалась наверх.
