# Finance Agent

Будущий универсальный финансовый агент. Должен уметь работать **с разными бизнесами** Максима — текущий (овощи и фрукты) и будущие (например, цемент).

## Принцип универсальности

Финагент должен:
- Работать с **любым** бизнесом, у которого есть стандартизированная финансовая модель (P&L, cashflow, акт сверки)
- Использовать общую базу знаний по финансовой методологии (находится в [20-domain/financial-reporting/](../../20-domain/financial-reporting/))
- Подключаться к разным БД через адаптеры — не быть привязанным к структуре данных конкретного бизнеса

Это **архитектурное требование** — учитывается при проектировании Евы (чтобы общие паттерны выделить в [_shared/](../_shared/) сразу).
