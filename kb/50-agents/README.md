# 50-agents — ИИ-агенты

Все ИИ-агенты, которые работают в периметре бизнеса.

## Структура

```
50-agents/
├── _shared/      Общее для всех агентов (память, инструменты, протоколы)
├── eva/          Текущий проект
└── finance/      Будущий универсальный финагент
```

## Реестр агентов

| Агент | Назначение | Статус | Файл |
|---|---|---|---|
| Eva | Основной интерфейс работы команды и контрагентов | в проектировании | [eva/](eva/) |
| Finance | Универсальный финагент для нескольких бизнесов | план на будущее | [finance/](finance/) |

## Принцип

Агенты — **класс сущностей**. Конкретные агенты — экземпляры.

- Универсальные правила (память, протокол инструментов, базовая архитектура) — в [_shared/](_shared/).
- Специфика каждого агента — в его подпапке.

## Текущий приоритет

**Eva** — единственный агент, который мы сейчас проектируем и реализуем. См. [eva/](eva/) и [roadmap](../65-roadmap/current.md).
