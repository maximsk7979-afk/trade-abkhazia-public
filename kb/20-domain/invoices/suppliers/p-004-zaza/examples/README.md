# Эталонные накладные Зазы (золотой датасет)

Эталонные пары `np-zaza-NNN.jpg` + `np-zaza-NNN.md` для регрессии и few-shot обучения Евы.

**Статус — скелет.** Папка создана 2026-05-19, эталоны пока не собраны.

## Целевой состав

10–15 накладных, разнообразных по сложности:
- **Лёгкие:** чистое фото, разборчивый почерк, простая компоновка (один покупатель)
- **Средние:** обычный почерк Зазы, обычная компоновка
- **Трудные:** рукописные правки, два покупателя на одном листе, плохое фото

Минимум 2 трудных примера — иначе валидация будет на лёгком конце и пропустит проблемы.

## Формат пары файлов

| Файл | Содержимое |
|---|---|
| `np-zaza-NNN.jpg` (или `.png`) | Исходное фото |
| `np-zaza-NNN.md` | Эталонная разметка |

Где `NNN` — трёхзначный номер по порядку добавления (001, 002, …).

## Формат файла разметки

См. общий [examples/README.md](../../../examples/README.md), раздел «Формат файла разметки».

Дополнительно для Зазы — заполнять:
- `supplier: П-004 (Заза)`
- `currency: GEL`
- В комментариях фиксировать, какие пары неоднозначностей (см. [recognition-rules.md](../recognition-rules.md)) встретились

## Правила формирования датасета

1. **Не редактировать фото** — берём как есть для честной валидации
2. **Разметка — это то, что Максим подтвердил как правильное**, не первичный ответ обученного чата
3. **Накладные из датасета НЕ используются для валидации новой системы** — иначе валидация необъективна. Свежие примеры для валидации — отдельно
4. **Включить как минимум 2 трудных примера** с рукописными правками или двумя покупателями
