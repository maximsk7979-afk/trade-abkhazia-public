## Единицы измерения и структурные элементы

| Элемент | Описание |
|---|---|
| Число в скобках `(10)`, `(20)` | Количество ящиков |
| Первое число после названия | Количество кг (для большинства) или ящиков (для тарных) |
| `×` (знак умножения) | Разделитель между кол-вом и ценой |
| `=` (знак равенства) | Перед итоговой суммой позиции |
| Число внизу с чертой | Общая сумма накладной |
| Зачёркнутое число | Исправление — верным считается новое |
| Числа после итога | Долги/предоплаты — **игнорировать** |

Универсальная структура строки — см. [`_common/invoice-structure.md`](../../_common/invoice-structure.md).
