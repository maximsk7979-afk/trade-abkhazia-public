# Правила распознавания товаров

Правила вида «контекст → товар»: как по неполным данным накладной (общее название, вес, цена, поставщик) однозначно определить SKU.

> **Статус — скелет.** Этот файл создан 2026-05-18 как место для приёма знаний из обученного Claude-чата (см. [extraction-prompts.md](extraction-prompts.md)). Содержимое наполняется ответами на запросы 2, 3 и 7 из листа запросов.
>
> Связан с [GAP-003](../../00-meta/gaps.md).

## 1. Правила «вес → сорт»

Когда в накладной указано общее название (например, «помидор»), сорт определяется по весу единицы упаковки.

> **Заполняется из ответа на Запрос 2** (правила определения сорта).
>
> Формат каждой записи:
> - **ПРАВИЛО**: <в одной фразе>
> - **ПРИЗНАКИ**: <вес единицы / цена / поставщик / соседние позиции>
> - **ИСКЛЮЧЕНИЯ**: <когда не работает>
> - **ПРИМЕР**: <конкретная накладная>

_(пусто)_

## 2. Правила «контекст → товар»

Известные правила (перенесены из [`georgian-dictionary.md`](georgian-dictionary.md)):

| Написано в накладной | Определяется как |
|---|---|
| «банан» (без уточнения) | Банан FP (SKU-028-01) |
| «dole» / «доле» | Банан DOLE (SKU-027-01) |
| «помидор» (без сорта) | Помидор классический → проверка по весу |
| Яблоко без сорта | Смотреть историю клиента, если нет — спросить |

> Будет расширено из ответов на Запрос 2 и Запрос 7.

## 3. Эвристики неоднозначностей

Случаи, где термин или контекст могут быть прочитаны двояко, и правило их различения.

> **Заполняется из ответа на Запрос 3** (эвристики неоднозначностей).
>
> Формат:
> - **ПАРА (или ситуация)**: <термин-1 vs термин-2, либо контекстная развилка>
> - **РАЗЛИЧИТЕЛЬ**: <какой признак однозначно решает>
> - **ПРИМЕР ОШИБКИ**: <как путалось раньше>
> - **ЭТАЛОН**: <как сейчас решается>

Стартовая запись (из [`georgian-dictionary.md`](georgian-dictionary.md)):

- **ვარდი (vardi) vs ბარდა (barda)** — графически похожи (одна буква разницы).
  - `ვარდი` = помидор розовый (сорт)
  - `ბარდა` = ракета (паприка)

> Будет расширено из ответа на Запрос 3.

## 4. Особенности поставщиков

> **Заполняется из ответа на Запрос 4** (особенности поставщиков).
>
> Если набирается более 5–7 поставщиков с характерными особенностями — выделить в отдельный файл `supplier-quirks.md`. Пока хранится здесь.
>
> Формат:
> - **ПОСТАВЩИК**: <название, как в накладных>
> - **ФОРМАТ**: <печатный / рукописный / смешанный>
> - **АССОРТИМЕНТ**: <обычные товары>
> - **СОКРАЩЕНИЯ**: <типовые>
> - **ОСОБЕННОСТИ**: <почерк, нумерация, ошибки>
