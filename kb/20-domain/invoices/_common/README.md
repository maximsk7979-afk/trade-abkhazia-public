# _common — общий слой

Знания, **применимые ко всем грузинским рукописным накладным**, независимо от поставщика. Сюда попадает то, что:

1. Безусловно общегрузинское (алфавит, рукописные графемы)
2. Универсальное по структуре (формат строки `(ЯЩИКИ) ТОВАР КОЛ-ВО × ЦЕНА = СУММА`)
3. Универсальное по процессу проверки (арифметика, форматы чисел)
4. Общие технические проблемы фото (обрезка, цифровые путаницы)

## Правило роста

Этот слой растёт **только при наблюдённой одинаковости у ≥2 поставщиков** (см. [ADR-011](../../../90-decisions/ADR-011-eva-supplier-segmentation.md), пункт 6). Антипаттерн — переносить сюда от теории к данным, до проверки на втором поставщике.

Сейчас фактически наблюдался только Заза. Содержимое `_common/` базируется на гипотезе, что эти явления универсальны для рукописных грузинских накладных. При появлении второго поставщика — провести сверку и при расхождениях вернуть пункт в его персональную базу.
