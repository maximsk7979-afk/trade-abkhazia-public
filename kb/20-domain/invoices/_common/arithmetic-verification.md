# Арифметическая проверка

Главный инструмент верификации правильности распознавания. Применимо к любой накладной с числовыми позициями.

## Правило позиции

```
КОЛ-ВО × ЦЕНА = СУММА
```

- **Допуск:** 1–3 лари на позицию — норма (округление копеек продавцом)
- **Расхождение > 5 лари** — сигнал об ошибке чтения одной из цифр
- **Действие при расхождении:** подобрать ближайшую цифру, при которой расчёт сходится. Кандидаты для замены — похожие цифры (см. [number-formats.md](number-formats.md))

## Правило итога

```
СУММА(всех позиций) ≈ ИТОГОВАЯ_СУММА
```

- **Допуск:** 4–13 лари на накладную — норма (накопленные округления позиций)
- **Расхождение > 50 лари** — сигнал, что пропущена строка или серьёзно неверно прочитано число в одной из позиций
- **Действие:** перепроверить позиции с наибольшими суммами или поискать пропущенную/обрезанную строку

## Проверка ящиков (логичность)

Число в скобках — всегда количество ящиков. Должно быть логичным для товара. Если получается аномально большое (например, 154 ящика авокадо) — захвачена лишняя цифра из следующего поля.

Типичные диапазоны количества ящиков см. в `suppliers/<id>/dictionary.md` или `price-ranges.md` конкретного поставщика — они меняются от поставщика к поставщику.

## Дополнительная проверка: средний вес ящика

```
ВЕС_ОБЩИЙ / КОЛ-ВО_ЯЩИКОВ = СРЕДНИЙ_ВЕС_ЯЩИКА
```

Каждый товар имеет характерный средний вес ящика. Аномальное значение (0.5 кг/ящик для баклажана или 50 кг/ящик для клубники) — сигнал об ошибке. Конкретные нормы — в `suppliers/<id>/price-ranges.md`.

## Зачёркивания

Если в позиции цифра зачёркнута и рядом написана новая — **верным считается незачёркнутое (новое) число**. Если непонятно, какое из двух зачёркнуто — проверять через умножение: какое даёт указанную сумму.
