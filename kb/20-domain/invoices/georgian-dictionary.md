# Словарь грузинских названий товаров

Соответствие грузинских названий товаров и наших товаров/SKU.

> **Контекст использования** (важно):
>
> Грузинские поставщики выписывают **рукописные накладные на грузинском**. Сейчас Максим переводит фото таких накладных через **отдельный обученный Claude-чат** в Claude.ai. Перевод выдаётся уже на русском — и только тогда передаётся в систему.
>
> **Старый бот v10** этим словарём НЕ пользовался — он работал с накладными, **уже переведёнными на русский** (см. [`business-rules-from-bot.md`](../business-rules-from-bot.md)).
>
> **Назначение этого файла**: подготовка к проектированию Евы. Когда Ева возьмёт на себя распознавание грузинских накладных, ей понадобятся как **этот словарь**, так и **полная база знаний** из обученного Claude-чата. Извлечение полной базы — задача [GAP-003](../../00-meta/gaps.md).
>
> **Статус — частичный**. Здесь стартовый словарь из 22 терминов, перенесённый из исходного CONTEXT.md (28 апреля 2026).

## Ключевое правило

**Помидор классический** (Т-001) — всегда **SKU-001-02** (пл.14кг, tw=0.5).

## Особые правила распознавания

| Написано в накладной | Определяется как |
|---|---|
| «банан» (без уточнения) | Банан FP (SKU-028-01) |
| «dole» / «доле» | Банан DOLE (SKU-027-01) |
| «помидор» (без сорта) | Помидор классический → проверка по весу |
| Яблоко без сорта | Смотреть историю клиента, если нет — спросить |

## Что ожидается от полной выгрузки

Из обученного Claude должны прийти (предположительно):
- Расширенный словарь (50+ терминов)
- Правила определения сорта по контексту (вес, цена, дата, поставщик)
- Эвристики для неоднозначных случаев
- База ошибок распознавания и их корректировки

См. [product-recognition.md](product-recognition.md) для правил уровня "контекст → товар".
