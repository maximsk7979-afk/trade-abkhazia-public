# Финансовая отчётность

**Только формы и правила формирования.** Реальные цифры — в БД и внешней бухгалтерии. См. [ADR-004](../../90-decisions/ADR-004-data-source-of-truth.md).

## Что будет внутри

- **accounting-rules/** — 🟢 **правила финансового учёта** (рабочий раздел): свод правил по каждой статье (`pay-categories-rulebook.md`) + журнал договорённостей (`decisions-log.md`) + метод работы. Наполняется по ходу настройки финучёта в TradeApp.
- **treasury-design.md** — 🟡 дизайн модели движения денег (кошельки, журнал движений, курс); этапы Ф-1/Ф-2 финблока
- **pnl-format.md** — 🟡 форма P&L: группы статей A/B/C + waterfall + оси проект/офис (этап Ф-3)
- **cashflow-format.md** — форма движения денежных средств
- **partner-act.md** — форма акта сверки с Лиёй
- **client-act.md** — форма акта сверки с клиентом
- **pricing-rules.md** — правила формирования прайса (краткая ссылка на [pricing.md](../pricing.md))
- **reporting-cadence.md** — когда какой отчёт формируется

⏳ Заглушка. Наполнение по мере проектирования отчётности.
