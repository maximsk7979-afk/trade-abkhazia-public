# Правила финансового учёта

> **Назначение раздела.** Здесь живут **операционные правила учёта** по каждой статье и каждому
> типу денежной операции: что вносим, кто/где/когда вносит, как это отражается в P&L / кассе /
> балансах. Это НЕ дизайн (дизайн модели — в [treasury-design.md](../treasury-design.md) и
> [pnl-format.md](../pnl-format.md)), а **свод договорённостей**, по которому потом пишется код и
> вводятся данные. Всё, о чём договариваемся по финучёту, фиксируется ЗДЕСЬ — чтобы не повторять.

## Метод работы (согласовано с владельцем 2026-07-01)

**Порядок реализации: сначала TradeApp (веб), потом Ева и мини-приложение.** Пока учёт не
настроен и не выверен в TradeApp — Еву и мини-апп по финансам не трогаем.

**Пошаговый цикл (по разделу «Справочники → Статьи»):**
1. Идём **по каждой статье** и определяем три правила: **заполнение** (что и как вносим),
   **внесение** (кто/где/когда, одна нога или две), **учёт** (P&L / касса / баланс).
2. Определяем **порядок статей внутри групп** (поле `ord`).
3. Договорённости по статье фиксируем в [pay-categories-rulebook.md](pay-categories-rulebook.md)
   и в [decisions-log.md](decisions-log.md).
4. Когда группа/статьи согласованы — **реализуем на программном уровне** (TradeApp).
5. Затем **вносим данные** по движению и расходу денег.
6. Выходим на **реальные балансы** с контрагентами и поставщиками.
7. После настройки TradeApp — переносим правила в **Еву и мини-апп** (интерфейсы к той же системе, ADR-025).

## Документы раздела

- [pay-categories-rulebook.md](pay-categories-rulebook.md) — **главный рабочий документ**: свод
  правил по каждой статье справочника `trade-cat-paycategories` (31 статья на 2026-07-01),
  сгруппировано по A/B/C, с полями заполнение / внесение / учёт / порядок.
- [decisions-log.md](decisions-log.md) — хронологический журнал финансовых договорённостей
  (каждое согласованное решение — датированная запись, чтобы не терялось между сессиями).
