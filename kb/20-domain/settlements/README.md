# Взаиморасчёты

Учёт долгов и платежей со всеми сторонами: клиентами, поставщиками, партнёрами, контрагентами.

## Файлы

- **clients.md** — с клиентами (выручка от продаж минус оплаты) ⏳ заглушка
- **suppliers.md** — с поставщиками товара (закупки минус оплаты) ⏳ заглушка
- **liya-partner.md** — с Лиёй как партнёром по рейсам 📝 наполняется при развёртывании
- **contractors.md** — с третьими контрагентами (водители, таможня, и т.д.) ⏳ заглушка
- **defect-refund.md** — возврат за брак ⏳ заглушка

## Принципиальное

В коде это всё — записи в `trade-settlements-v2` с разными `acctType`:
- `client`, `supplier`, `partner`, `expense`, `warehouse`

Ручные операции (`opType`):
- `payment` — оплата
- `charge` — начисление
- `defect_refund` — возврат за брак
- `balance` — корректировка баланса

Автоматические — выводятся из `trip.expenses[]`, `trip.supplierPayments[]`, продаж и т.д.

См. [40-system/frontend.md](../../40-system/frontend.md), модуль "Взаиморасчёты".
