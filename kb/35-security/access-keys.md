# Инвентарь доступов и ключей

> Что где лежит и **что отзывать**, если машина потеряна. Сами секреты — в
> `~/secrets-trade/credentials.md` (режим 600, вне git) и в менеджере паролей.

## Машины

| Машина | Адрес | Роль | Вход |
|---|---|---|---|
| Боевой `trade-server` | 108.61.167.168 | магазин, Ева, Postgres, nginx | пароль (ноутбук) + ключ станции |
| Рабочая станция | 95.179.184.95 | Claude Code, разработка | только ключ, пароль отключён |
| Ноутбук (macOS) | — | резервное рабочее место | — |

## Ключи (заведены 2026-08-29)

| Ключ | Откуда | Куда | Файл |
|---|---|---|---|
| `trade_workstation` | ноутбук | рабочая станция | `~/.ssh/trade_workstation` (ноутбук) |
| `id_ed25519` станции | станция | боевой сервер | `~/.ssh/id_ed25519` (станция) |
| `id_ed25519` станции | станция | GitHub | тот же, добавлен в аккаунт как `trade-workstation` |

Ключ с ноутбука на боевой **не заводился** — с ноутбука деплой идёт по паролю
через `sshpass`, как и раньше.

## Если потеряна рабочая станция

Сделать сразу, иначе ключи останутся действующими:

1. **GitHub** → Settings → SSH and GPG keys → удалить ключ `trade-workstation`.
2. **Боевой сервер** → убрать строку станции из `~/.ssh/authorized_keys`:
   ```bash
   ssh root@108.61.167.168 "sed -i '/trade-workstation/d' ~/.ssh/authorized_keys"
   ```
3. Пересоздать станцию по [workstation-rebuild.md](../70-operations/runbooks/workstation-rebuild.md) — там генерируются новые ключи.

Ничего из боевых данных при этом не теряется: станция держит только копию репозитория,
эталон которого в GitHub.

## Если потерян ноутбук

1. **Рабочая станция** → убрать ключ ноутбука:
   ```bash
   ssh root@95.179.184.95 "sed -i '/mac->trade-workstation/d' ~/.ssh/authorized_keys"
   ```
2. Сменить пароль боевого сервера в панели Vultr (он лежал в `credentials.md` на ноутбуке)
   и обновить `credentials.md` на станции и в менеджере паролей.
3. Сменить пароли веб-входа TradeApp, если ноутбук мог попасть в чужие руки.

## Правило

Секреты живут в **трёх** местах: ноутбук, рабочая станция, менеджер паролей.
В git — никогда. Двух копий мало: обе машины могут пропасть одновременно.
