- Остаток: гранулярная ролевая матрица веб-поверхности (сейчас: полный доступ / demo-чтение) — [GAP-048](../00-meta/gaps.md#gap-048).

## Принципы

1. **Posterior данные** (продажи, выручка, P&L) — доступ только Максиму, бухгалтеру, оп-менеджеру (с ограничениями).
2. **Закупочные цены** — не показываются клиентам и менеджерам продаж.
3. **Чужие продажи** — менеджер продаж видит только свои.
4. **Контрагенты-партнёры** (Лия) — видят только свои операции.

Детальная матрица — будет в `role-permissions.md`.
