# Поставщик (TO-BE, внешняя роль)

> Роль `supplier` — **внешний актор** (не сотрудник). Опознаётся по полю `tgChatId` в карточке
> поставщика (`trade-cat-suppliers`). **Изолированный скоуп** ([ADR-022](../../../90-decisions/ADR-022-role-model-rbac.md)):
> поставщик общается только с Евой по вопросам закупки и **не имеет доступа ни к каким данным
> системы**. Статус — плумбинг роли реализован (2026-06-09), но ни один поставщик ещё не
> подключён (`tgChatId` не задан) — роль **дормантна**.

## Назначение

Поставщик поставляет товар компании (для банана — Рамаз `П-005`, Уча — завести). В целевой
модели поставщик ведёт с **Евой переписку в Telegram** по конкретной поставке: принимает заказ
на объём, подтверждает отгрузку, выставляет накладную.

## Текущий держатель роли

- **Рамаз БАНАНЫ** (`П-005`, GEL/GE/PRJ-004) — настроен в системе, к Еве не подключён.
- **Уча БАНАНЫ** — завести (GEL/GE/PRJ-004).

## Зоны ответственности (со стороны поставщика, как видит компания)

- Принять/отклонить заказ на объём банана на день D4 (4 дня на подготовку/дозревание).
- Подтвердить отгрузку.
- Выставить накладную (PDF, грузинский язык) на согласованный объём X+Y с данными водителя.
- При наличии — сообщить о свободном спотовом объёме (для увеличения лимита).

## Что поставщику НЕ доступно (изоляция)

- Никаких инструментов данных Евы. Не видит: отпускные цены, клиентов, балансы, маржу,
  обороты, других поставщиков. Системный промпт Евы для поставщика — отдельный, изолированный.

## Взаимодействует с

- **Ева**: основная и единственная системная поверхность — переписка по закупке (исходящие
  инициирует Ева). Сценарий — [banana-procurement-orchestration.md](../../../50-agents/eva/scenarios/banana-procurement-orchestration.md).
- **Генеральный директор**: напрямую (вне системы) — согласование увеличения объёма (спот).
- **Закупщик / водитель**: физически у поставщика на погрузке (Фаза 1, шаг 10).

## Доступ к данным

Внешний изолированный скоуп — см. [35-security/role-permissions.md](../../../35-security/role-permissions.md)
и [role-catalog.md](../../../35-security/role-catalog.md). Гейтинг fail-closed; поставщик не
получает ни одного инструмента данных.
