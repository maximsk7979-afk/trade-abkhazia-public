# TO-BE — Роли как должны работать с Евой

Целевое состояние после внедрения Евы и новой системы учёта. Роли пересматриваются: часть функций передаётся Еве, часть переопределяется между людьми.

## Зачем

- Понимать, **куда** идём
- Опираться при проектировании Евы
- Принимать решения по миграции

## Источник

Проектирование TO-BE-ролей идёт совместно: Максим + Архитектор + CC. Старт — после получения и укладки AS-IS.

## Принципы трансформации

(будут зафиксированы по мере проектирования)

- Какие функции передаются Еве
- Какие функции переопределяются между ролями
- Какие новые роли появляются (например, экспедитор)

См. [ADR-006](../../90-decisions/ADR-006-as-is-to-be-principle.md).
