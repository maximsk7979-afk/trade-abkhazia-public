# Экспедитор (TO-BE, с Евой)

> Целевое состояние роли экспедитора. **Сейчас отдельных экспедиторов в команде нет** — функции совмещают [менеджеры продаж](../sales-manager/README.md) (см. [AS-IS-снимок](../../as-is/README.md) и [GAP-013](../../../00-meta/gaps.md#gap-013)). Роль описана заранее, чтобы: (1) корректно обучить Еву работе с экспедитором как отдельной ролью; (2) подготовить базу к найму выделенных экспедиторов. Принцип AS-IS/TO-BE — [ADR-006](../../../90-decisions/ADR-006-as-is-to-be-principle.md). Структура «роль ↔ процесс ↔ сценарий Евы ↔ инструкция» — [ADR-015](../../../90-decisions/ADR-015-role-process-eva-structure.md).

## Назначение

Экспедитор доставляет заказанный товар клиентам: загружает машину со склада, везёт по маршруту, **взвешивает весовые позиции у клиента при выдаче**, фиксирует фактическую отгрузку и сумму, принимает оплату и возвращает непроданное на склад. Это «последняя миля» — превращение заявки (ЗР/ЗД) в **состоявшуюся продажу** с точной суммой и оплатой.

## Текущий держатель роли

Выделенного экспедитора **нет**. Функции совмещают менеджеры продаж (режим «Менеджер продаж + Экспедитор»). При найме выделенного экспедитора продажная часть остаётся у менеджера, а отгрузка/доставка/возвраты переходят экспедитору. Конкретные люди — [`15-team/`](../../../15-team/).

## Зоны ответственности

- **Сбор и загрузка доставки** (Д-XXX): из заявок, готовых к отгрузке (ЗР «На складе», ЗД «Новая»), + допобъём из свободного остатка машины.
- **Доставка по маршруту** и выдача товара клиентам.
- **Фиксация факт-отгрузки** по каждому клиенту: для весовых — **взвешивание у клиента** (тар × брутто → нетто), для тарных (банан и т. п.) — по количеству упаковок; цена по умолчанию — **замороженная согласованная** при заказе, правится при необходимости.
- **Приём оплаты** от клиента и фиксация (`shipmentPaid`); недоплата уходит в долг клиента.
- **Допродажа** из свободного объёма машины (клиент взял больше / другой товар).
- **Возврат непроданного** на склад при завершении доставки (восстановление FIFO-остатка).
- Расходы доставки (аренда машины, грузчик) — фиксируются при завершении.

## Функции

### Регулярные
1. **Сформировать доставку** — выбрать готовые заявки, при необходимости добавить доп. объём, отправить машину («Выехали»).
2. **Отгрузить клиенту** — по каждому клиенту в доставке зафиксировать факт (вес/количество, цену, оплату), нажать «✅ Отгружено».
3. **Завершить доставку** — оформить возвраты на склад и расходы доставки.

### Эпизодические
- Допродажа товара из свободного объёма машины.
- Пересмотр цены строки у клиента (рынок двинулся / договорённость на месте) — в пределах полномочий; крупные отклонения — к владельцу/менеджеру.
- *(Отложено — [GAP-031](../../../00-meta/gaps.md#gap-031)/[GAP-032](../../../00-meta/gaps.md#gap-032))* — частичная нехватка на рейсе, брак/возврат скоропорта при доставке.
- *(Перспектива — [GAP-020](../../../00-meta/gaps.md#gap-020))* — фото отгрузочной накладной через Еву + распознавание.

## Взаимодействует с

- **Менеджер продаж**: передаёт готовые заявки клиентов; получает обратную связь по факту отгрузки, недостачам, возвратам, оплате.
- **Кладовщик / склад**: получает товар на загрузку, возвращает непроданное.
- **Клиент**: выдаёт товар, взвешивает у клиента, принимает оплату.
- **Ева**: уведомления о заявках/рейсах; в перспективе — фиксация отгрузки и фото накладной через Telegram ([GAP-020](../../../00-meta/gaps.md#gap-020)).
- **Владелец**: согласование крупных отклонений цены, нестандарта.

## Использует функции системы

- **trade_app** (сейчас) — модуль «🚚 Доставки»: формирование доставки, форма отгрузки клиенту (`ClientShipmentEditor`), завершение доставки, печать накладной.
- **Ева / Telegram** (перспектива) — фиксация отгрузки и фото накладной ([GAP-020](../../../00-meta/gaps.md#gap-020)); уже сейчас — уведомления.

> Экспедитор работает в **обоих** интерфейсах: основная фиксация — в trade_app; Ева — для уведомлений и (в будущем) мобильной фиксации с телефона у клиента.
