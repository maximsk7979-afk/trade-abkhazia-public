# AS-IS — Роли как они работают сейчас

Это **снимок текущего состояния** бизнеса до перехода на новую систему и Еву. "Фото" того, как функционируют роли в момент 2026-04-28.

## Зачем

- Помнить, **откуда** пришли
- Сравнивать с TO-BE при принятии решений по миграции
- Объяснять "почему сейчас так"

## Дата фиксации

2026-04-28 — старт развёртывания базы знаний.

## Источник

Описания AS-IS-ролей будут получены от Максима из его чата с Архитектором (там накоплено за многие сессии). Задача в [roadmap](../../65-roadmap/current.md).

После получения CC уложит описания сюда по [шаблону](../../00-meta/templates/role-template.md).

## Зафиксированные факты AS-IS (по ходу работы)

- **Совмещение «Менеджер продаж + Экспедитор» (на 2026-06-06).** Выделенных экспедиторов в команде нет — функции экспедитора (сбор доставки, развоз, **взвешивание у клиента**, выдача, приём оплаты, возвраты на склад) выполняют **менеджеры продаж**. Целевое разделение — отдельная роль [экспедитора (TO-BE)](../to-be/expeditor/README.md); при найме продажная часть остаётся у менеджера, отгрузка/доставка переходят экспедитору. См. [GAP-013](../../00-meta/gaps.md#gap-013).

## Жизненный цикл AS-IS файлов

Когда роль завершит миграцию (TO-BE стал реальностью):
- TO-BE-файл становится активным состоянием в `30-roles/<role>.md`
- AS-IS-файл переезжает в `99-archive/2026-roles-as-is/`

См. [ADR-006](../../90-decisions/ADR-006-as-is-to-be-principle.md).
