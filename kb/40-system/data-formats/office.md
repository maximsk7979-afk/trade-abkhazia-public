# Office — JSON-формат офиса/склада

## Storage

- Ключ: `trade-cat-offices`
- JS-константа: `SK_OFF`
- Содержимое: массив объектов

## Формат

```json
{
  "id": "О-001",
  "n": "Сухуми",
  "active": true
}
```

## Поля

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | ID с префиксом О (`О-001`) |
| `n` | string | Название офиса/склада |
| `active` | boolean | Активен ли |

## Принцип

**Офис = склад** — единая сущность. Нет разделения на офисы и склады.

Текущие офисы (тестовая база):
- О-001 Сухуми
- О-002 Гагра
- О-003 Гудаута

## Использование officeId в других сущностях

| Сущность | Поле | Назначение |
|---|---|---|
| Рейс | `trip.officeId` | Целевой склад рейса |
| Партия FIFO | `batch.officeId` | На каком складе лежит |
| Продажа | `sale.officeId` | С какого склада отгружено |
| Складская операция | `whOp.officeId` | По какому складу |
| Доставка | `delivery.officeId` | С какого склада |
| Сотрудник | `staff.officeId` | Привязка к офису |

Клиент **не привязан** к офису — может покупать с любого.
