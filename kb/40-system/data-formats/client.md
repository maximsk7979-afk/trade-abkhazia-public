# Client — JSON-формат клиента

## Storage

- Ключ: `trade-cat-clients`
- JS-константа: `SK_CLI`
- Содержимое: массив объектов

## Формат

```json
{
  "id": "К-007",
  "n": "Аршак",
  "pt": "mid",
  "saleType": "ds",
  "wa": "+7...",
  "tg": "@username",
  "tgChatId": "123456789",
  "ynavUrl": "https://yandex.ru/maps/...",
  "managerId": "С-XXX"
}
```

## Поля

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `id` | string | да | ID с префиксом К (`К-007`) |
| `n` | string | да | Имя/название клиента |
| `pt` | string | да | Тип цены: `opt` / `mid` / `ret` |
| `saleType` | string | нет | По умолчанию: `ps` (со склада) или `ds` (доставка). Используется ботом/Евой для автоопределения типа продажи |
| `wa` | string | нет | WhatsApp |
| `tg` | string | нет | Telegram (`@username` или номер) |
| `tgChatId` | string | нет | Chat ID для будущего бота-клиента |
| `ynavUrl` | string | нет | URL геолокации в Yandex Картах для водителей |
| `managerId` | string | нет | Закреплённый менеджер продаж (С-XXX, роль `sales_manager`). При создании продажи копируется в `sale.managerId` |

## Типы цены (`pt`)

| Код | Расшифровка |
|---|---|
| `opt` | Оптовая |
| `mid` | Средний опт |
| `ret` | Розница |

См. правила прайса в [20-domain/pricing.md](../../20-domain/) (заглушка, наполнение позже).

## Типы продажи (`saleType`)

| Код | Расшифровка |
|---|---|
| `ps` | Продажа со склада (sale-direct) — клиент сам забирает |
| `ds` | Продажа доставкой (order-stock) — клиент получает с доставкой |

Поле используется при создании новых продаж/заявок для **автоматического** определения типа. Если поле пустое — Ева/бот определяет по истории клиента (см. [50-agents/eva/scenarios/](../../50-agents/eva/scenarios/), будущий файл).

## Особые случаи

- **Разовый клиент ("с улицы")** — clientId в продаже задаётся как `__walk_in__`, имя пишется в `saleData.clientName`. В справочнике клиентов **не создаётся**.
- **Клиент-партнёр** (К-006 = Лия) — обычная запись в справочнике, при этом тот же человек ещё фигурирует как партнёр в `trip.partners[]`. См. [20-domain/settlements/liya-partner.md](../../20-domain/settlements/liya-partner.md).

## Связи

- `id` → используется в `sale.clientId`
- `managerId` → ссылка на сотрудника в `trade-cat-staff`
- Клиент **не привязан** к складу — отгрузки могут быть с любого офиса

## Особенности

- Имена полей **сокращены** (`n`, `pt`, `wa`, `tg`) — историческое решение
- Все строковые
