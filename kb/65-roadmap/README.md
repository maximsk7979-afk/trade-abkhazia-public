# 65-roadmap — План развития

## Что внутри

- [current.md](current.md) — актуальный план

## Принцип

Roadmap — это **намерения**, не обязательства. Меняется по мере уточнения приоритетов.

## Кто обновляет

CC (автоматически) после каждого значимого решения. См. [maintenance.md](../00-meta/maintenance.md), Обязательство 1.

Триггеры обновления:
- Задача завершилась → перенос в [CHANGELOG](../95-changelog/) и удаление из roadmap
- Новый ADR порождает задачу → добавление в roadmap
- Меняется приоритет → перестановка
