# Кладовщик: как сверять остатки (коротко)

> Вторичный слой над [процессом](../../30-roles/to-be/warehouse/processes/inventory-reconciliation.md). Для человека на складе.

## Каждый вечер

1. Ева пришлёт напоминание «Пора сверить остатки». Открой приложение → вкладка **«📋 Сверка»** → **«Новая сверка»**.
2. По каждой позиции система показывает **книжный остаток** (сколько должно быть мест). Пересчитай товар руками и впиши **сколько по факту мест**.
3. Если цифры сходятся — увидишь зелёное «✓ сходится». Если нет — красным покажет **недостачу** или **излишек**.
4. Если по позиции **взвешивал** — впиши факт. вес в кг (поле «Вес факт»). Если не взвешивал — оставь пустым.
5. Где есть расхождение — впиши **причину** (бой / пересорт / усушка / ошибка).
6. Нажми **«Закрыть сверку»**. Готово — результат уходит владельцу/ГД в утренней сводке.

## Важно

- Считай **только свой склад** — приложение покажет твой склад автоматически.
- Места считаем **каждый день**; вес — только если просят или сам взвешивал.
- Сверка ничего не списывает сама — она фиксирует расхождение, разбирается владелец/ГД.
- Не успел вечером — сделай утром до начала работы; лучше поздно, чем пропуск.

## Если что-то не так

- Товара нет в списке, а по факту есть → впиши его (если есть в каталоге) — пометится как пересорт.
- Сомневаешься в книжной цифре → всё равно впиши **реальный** факт; расхождение для того и нужно.
- Вопросы по цифрам — спроси Еву: «покажи расхождения по сверке».
