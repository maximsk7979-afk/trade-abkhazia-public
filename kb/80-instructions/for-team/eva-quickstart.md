# Памятка: как работать с Евой

> Короткая шпаргалка для менеджера. Полная инструкция — [sales-manager.md](./sales-manager.md). Еву можно переспросить в любой момент своими словами.

**Ева** — ИИ-помощник Trade Abkhazia в Telegram. Через неё ты заводишь клиентов, подключаешь их к приложению и оформляешь заявки.

## 1. Вход

1. Открой в Telegram бота **@trade_abkhazia_sales_bot**.
2. Напиши **`/start`**. Ева поздоровается и обратится по имени — значит, узнала тебя. Если пишет «сервис в тестовом режиме» — твой аккаунт ещё не подключён, скажи Максиму.

## 2. Завести нового клиента

1. Напиши Еве: **«заведи нового клиента»** (или просто «новый клиент»).
2. Ева спрашивает **по одному вопросу** — отвечай по очереди. Поля-выбор приходят **кнопками**:
   - **Название** (магазин/компания) — уникальное;
   - **Контактное лицо** — как обращаться к клиенту;
   - **Проекты** — отметь галочками (бананы / турецкие / грузинские овощи и т. д.), потом «Готово»;
   - **Сегмент**, **уровень цены** (опт / ср.опт / розница);
   - **Способ доставки** — 🚚 Доставка или 🏬 Самовывоз (по умолчанию подставится в заявку клиента);
   - **WhatsApp** клиента (в формате `+7…`);
   - **Яндекс-навигатор** (ссылка на точку) — можно пропустить;
   - **Фото витрины/входа** — пришли фото или напиши «без фото».
3. Прервать опрос — напиши «отмена/стоп». Можно начать заново.

## 3. Подключить клиента к приложению

1. После заведения Ева пришлёт **ссылку-приглашение**.
2. **Перешли эту ссылку клиенту** (в WhatsApp/Telegram).
3. Клиент жмёт ссылку → его Telegram привязывается, Ева его приветствует, **тебе придёт уведомление** «клиент подключился». Ссылка действует **14 дней**.
4. У клиента появляется кнопка **🍌 Заказ** (мини-приложение) — он сам оформляет заявки.

## 4. Оформить заявку за клиента

Если клиент не пользуется приложением — оформи за него:
1. Открой мини-апп (кнопка **🍌 Заказ** у поля ввода) → выбери **своего клиента** сверху.
2. **«На какой день?»** — выбери дату доставки (завтра / +2 / +3 / +4).
3. Отметь количество по позициям (ассортимент — только из проектов клиента), при необходимости переключи **Самовывоз/Доставка**.
4. **Оформить** — заявка уйдёт, тебе и Максиму придёт уведомление.

> Цена и сумма считаются автоматически. По весовым (помидоры, огурцы) сумма **ориентировочная** — точная после взвешивания при отгрузке. Заявку можно изменить/отменить **до отсечки** (накануне 20:00).

## 5. Правила

- **Цена клиенту — строго по его прайсу.** Торг, скидку, нестандарт — **не обещай сам**, передай Максиму (Ева эскалирует).
- **Конфиденциальность:** клиент видит только своё (свои цены/заказы/баланс). Чужие данные, закупочные цены, маржу — не раскрывай.

## Что видит Максим

Максиму (владельцу) автоматически приходят уведомления о действиях через Еву: **новый клиент**, **подключение клиента**, **новая/изменённая заявка**, **отмена заявки**.

## Если что-то не так

- Ева не узнаёт / «тестовый режим» → скажи Максиму (нужно добавить твой Telegram).
- Ошибся в данных клиента → правится в веб-приложении (Справочники → Клиенты) или попроси Максима.
- Непонятно — просто спроси Еву своими словами.
