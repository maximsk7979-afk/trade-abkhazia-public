# 80-instructions — Сгенерированные инструкции

Это **вторичный слой**. Здесь живут документы, **собираемые из первоисточников**:

- Должностные инструкции для сотрудников
- Регламенты ежедневной работы
- Инструкции для клиентов и контрагентов (как пользоваться Евой)
- Описания интерфейсов

## ⚠️ Принципиальное

Документы здесь — **не первоисточники**. Они **ссылаются** на:
- [`20-domain/`](../20-domain/) — бизнес-правила
- [`30-roles/`](../30-roles/) — описания ролей
- [`40-system/`](../40-system/) — система
- [`50-agents/eva/`](../50-agents/eva/) — Ева

**Если ты редактируешь файл здесь и видишь, что нужно изменить факт — иди править первоисточник.** Документ здесь **перегенерируется** из обновлённого источника.

## Что внутри

- **for-team/** — для сотрудников (должностные инструкции, регламенты)
- **for-clients/** — для клиентов
- **for-contractors/** — для контрагентов (Лия и др.)
- **interfaces/** — инструкции по интерфейсам (frontend admin, Eva в Telegram)

⏳ Заглушка. Подпапки и файлы создаются по мере появления первой реальной инструкции.

## Кто и когда генерирует

CC, по запросу. Триггеры:
- Максим просит должностную инструкцию для нового сотрудника → CC собирает из первоисточников
- Появляется новый клиент → CC может сгенерировать стандартную инструкцию по Еве
- Новая роль внедрена → CC создаёт `<role>-onboarding.md`

См. [maintenance.md](../00-meta/maintenance.md), Обязательство 1.
