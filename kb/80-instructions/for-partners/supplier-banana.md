# Памятка поставщику бананов

> Первая инструкция для **внешнего** партнёра (роль `supplier`, ADR-022 — изолированный скоуп).
> Часть 1 — показать/пересказать поставщику; Часть 2 — чек-лист подключения для Максима.

## Часть 1 — для Рамаза (простым языком)

**Ева — наш помощник в Telegram.** Она помогает нам с тобой не терять заказы: пишет вовремя,
ничего не забывает и сразу передаёт твой ответ нам.

**Как это работает:**

1. **Когда нам нужны бананы, Ева напишет тебе заказ** — сколько ящиков и на какой день.
   Например: «Заказ: 100 ящиков, доставка 15 июня. Подтверждаешь?»
2. **Ты отвечаешь обычным текстом**, по-русски, как удобно: «подтверждаю», «да, 100 будет»,
   или «100 не соберу, могу 80» — Ева поймёт и передаст нам.
3. **Если что-то меняется** (не успеваешь, нет объёма, вопрос по цене) — просто напиши ей
   об этом, она сразу сообщит Максиму и закупщику. Договорённости по цене и деньгам — как
   и раньше, напрямую с Максимом; Ева деньги не считает и не принимает.
4. **Перед отгрузкой** Ева может спросить данные для накладной и водителя — ответь ей текстом.

**Что важно знать:**
- Ева отвечает **только по нашим с тобой поставкам**. Никаких чужих данных она не показывает
  и не обсуждает — ни цены магазинам, ни других поставщиков.
- Пиши в любое время — она не спит. Если вопрос не к ней, она передаст людям.
- Это **не замена** общения с Максимом — это способ ничего не потерять.

## Часть 2 — чек-лист подключения (для Максима)

> ⚠️ Техническая тонкость Telegram: **бот не может написать человеку первым.** Рамаз должен
> сам один раз открыть бота и нажать Start — только после этого Ева сможет ему писать.

1. **На месте у Рамаза:** открой ему ссылку `t.me/trade_abkhazia_sales_bot` → он жмёт
   **Start** → пишет любое слово (например «Привет»).
2. Ева ответит отказом «вас нет в системе» — **это нормально**, его chat_id ещё не привязан.
   Зато его chat_id теперь есть в логах Евы.
3. **Привязка:** скажи CC в сессии «привяжи Рамаза, он только что написал Еве» — CC возьмёт
   chat_id из логов и впишет в карточку **П-005** (`tgChatId`). Вручную: trade_app →
   Справочники → Поставщики → П-005 → поле Telegram chat ID (chat_id смотрим
   `pm2 logs eva` на VPS).
4. **Подожди ~1 минуту** (кэш идентификации Евы), затем пусть Рамаз напишет ещё раз —
   теперь Ева ответит ему уже как поставщику (изолированный режим).
5. **Проверка изоляции:** попроси Рамаза спросить у Евы что-нибудь «запретное» («какие цены
   у магазинов?», «какой у вас оборот?») — Ева должна вежливо отказать. Это тест GAP-030/ADR-022.
6. То же самое потом для **Учи** (карточку «Уча БАНАНЫ» предварительно завести: GEL/GE/PRJ-004).

**После подключения обоих поставщиков** можно включать ежедневный автопоток закупки:
`PROCUREMENT_KICKOFF_ENABLED=1` в `/var/www/eva/.env` + restart (см. roadmap, инкремент 1.6).
